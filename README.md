## 🚀 Projetos em destaque

### 1. ⚙️ Automação de controles de Segurança do Trabalho

**Objetivo:** automatizar o acompanhamento de vencimentos de ASO e treinamentos obrigatórios, facilitando a identificação de pendências.

**Tecnologias:** n8n, JavaScript, planilhas, e-mail e Power BI.

**O que o projeto busca demonstrar:**
- Leitura e organização de registros.
- Identificação de vencimentos e prazos.
- Envio automatizado de alertas.
- Visualização de indicadores para apoiar decisões.

### 2. 📊 Business Intelligence com Power BI

**Objetivo:** transformar dados operacionais em indicadores visuais para acompanhamento de desempenho.

**Tecnologias:** Power BI, DAX, Excel e modelagem de dados.

**Competências a demonstrar:**
- Construção de KPIs.
- Tratamento e modelagem de dados.
- Criação de medidas e filtros.
- Desenvolvimento de dashboards para tomada de decisão.

### 3. 🐍 Engenharia de Dados com Python e SQL

**Objetivo:** desenvolver um pipeline de dados capaz de extrair, transformar, validar e preparar informações para análise.

**Tecnologias:** Python, SQL e ferramentas de engenharia de dados.

**Etapas previstas:**
- Extração de uma fonte de dados.
- Limpeza e transformação.
- Validação da qualidade dos registros.
- Organização dos dados para consulta e análise.

### 4. 🤖 Automação inteligente com n8n e IA

**Objetivo:** integrar aplicações e automatizar tarefas por meio de workflows, APIs e recursos de inteligência artificial.

**Competências a demonstrar:**
- Integração entre sistemas.
- Processamento de dados.
- Uso de APIs.
- Tratamento de erros e monitoramento de execuções.

> Os projetos descritos representam minhas iniciativas de portfólio. A documentação, o código e as evidências de execução serão disponibilizados nos respectivos repositórios à medida que cada projeto estiver pronto.
